1. Classic Outlook (Windows): select yesterday's mail (click the first, Shift+click the last), then drag the selection onto the incoming folder in File Explorer. Each message is saved as a .msg with its attachments inside.
  2. New Outlook / Outlook on the web: open a message, choose … → Save as (or Download), and save the .eml into the incoming folder. Dragging to the folder works too.
  3. Outlook for Mac: drag messages from the list into the incoming folder in Finder.
  4. Then click Process new mail on the Today page, or double-click CloseDesk in the project folder.

The drop folder is {{ inbox_incoming }}. A desktop shortcut to it makes this a ten-second job. Dropping the same email twice is fine — it is recognized and not filed twice.
