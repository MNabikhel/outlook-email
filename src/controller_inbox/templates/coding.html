How codes are matched

  • On the invoice: a code from your workbook stamped or typed on the invoice or in the email, even where a scan read a period as a comma or an O for a zero.
  • You used it for this sender: no code printed, so the code you last confirmed for the same sender.
  • Description matches: otherwise, a description whose words are on the invoice.

Nothing is final until you confirm it. Revise lets you pick other codes, or several for a split invoice. Search all mail finds an invoice by its code or description.
