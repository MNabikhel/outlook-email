Drop folder on this laptop

Copy this project onto the laptop, then drop mail here. You do not need a cloud login to start.

  1. Save or drag Outlook messages into {{ inbox_incoming }} as .msg or .eml.
  2. Attachments inside the message are unpacked on their own. If you also have the files separately, put them in {{ inbox_attachments }}/<same name as the message>/.
  3. Excel, PDF, Word, PowerPoint, CSV, RTF, HTML, ZIP, and older .xls workbooks are read. A loose file dropped in Incoming is classified too.
  4. Click the button below, or run python -m controller_inbox ingest. Processed originals move to inbox/processed. Unpacked files land in inbox/extracted.

Scripts extract. Bionic decides.

The fast scripts pull text, amounts, dates, and file types, then leave a draft in Important, Informational, or Reference. The local model in Bionic Studio does the reading: category, folder, summary, and action items. A payment-instruction warning stays in Important either way.

In LM Studio, load a model, start the local server, and install the bionic/closedesk-inbox skill. Then set:

CONTROLLER_INBOX_LLM=true
CONTROLLER_INBOX_LLM_BASE_URL=http://127.0.0.1:1234/v1
CONTROLLER_INBOX_LLM_MODEL=local-model

Status: {{ 'Bionic reader on' if llm_enabled else 'script drafts only — Bionic off' }}

Overnight: python -m controller_inbox overnight. Or ask Bionic to run the closedesk-inbox skill, which calls the same tools. local-model means “whatever LM Studio has loaded.” Waiting on Bionic: {{ counts.waiting_on_bionic }}.

When a category is wrong, open the message and use “Wrong category?”. The reason is saved, the overnight run will not overwrite that message, and the example is written to data/training/corrections.jsonl. A saved correction cannot clear a payment-instruction warning on a new message.
