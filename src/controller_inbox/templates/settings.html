How this runs

  1. CloseDesk reads mail through Microsoft Graph (Microsoft 365 / Outlook).
  2. It pulls the body plus every attachment, extracts text from PDF, Excel, Word, and CSV, and redacts account numbers.
  3. Finance-specific rules classify the file (invoice, bank statement, payroll, PBC request, payment-instruction change, and so on) and score importance.
  4. Action items are extracted for you: enter invoice, apply cash, reconcile, approve T&E, complete PBC, do not process a wire-instruction change.
  5. A daily digest rolls the open list together. Optional Outlook write-back flags the message in your mailbox.

Microsoft 365 setup

  1. In Entra ID, register an app (public client / mobile & desktop).
  2. Enable “Allow public client flows”.
  3. Add delegated Graph permissions: Mail.Read, User.Read. Add Mail.ReadWrite to flag messages, Mail.Send to email the digest.
  4. Copy the application (client) ID into .env as AZURE_CLIENT_ID.
  5. Run python -m controller_inbox auth, then sync or watch.
