Drop folder on this laptop

Copy this project onto the laptop, then drop mail here. You do not need a cloud login to start.

  1. Save or drag Outlook messages into {{ inbox_incoming }} as .msg or .eml.
  2. Attachments inside the message are unpacked on their own. If you also have the files separately, put them in {{ inbox_attachments }}/<same name as the message>/.
  3. Excel, PDF, Word, PowerPoint, CSV, RTF, HTML, ZIP, and older .xls workbooks are read. A loose file dropped in Incoming is classified too.
  4. Click the button below, or run python -m controller_inbox ingest. Processed originals move to inbox/processed. Unpacked files land in inbox/extracted.

Rules, then a local model

Scripted rules pull invoice numbers, amounts, due dates, and payment-instruction changes. Those stay in charge. A local model is optional and only suggests a category when the rules are unsure.

Run Ollama (or any local agent with an OpenAI-compatible API, including a Bionic-style agent) and set:

CONTROLLER_INBOX_LLM=true
CONTROLLER_INBOX_LLM_BASE_URL=http://127.0.0.1:11434/v1
CONTROLLER_INBOX_LLM_MODEL=llama3.2

Status: {{ 'local model on' if llm_enabled else 'rules only — local model off' }}

When a category is wrong, open the message and use “Wrong category?”. The reason is saved and applied to the next message from that sender. The same examples are written to data/training/corrections.jsonl if you later fine-tune a local model. A saved correction cannot clear a payment-instruction warning on a new message.
