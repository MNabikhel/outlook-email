Check again

The fast scripts pull text, amounts, dates, and file types, then file a draft. The model reads that short packet — never the raw files — and writes the category, folder, a one-line summary, and tasks. The most important mail is read first.

In Ask CloseDesk, the model reads the text pulled from attachments (PDF pages, workbook cells and formulas, Word drafts with tracked changes, slides) and can open other emails and their files to answer. It notes what it finds and checks its answer against those notes. Files on an email flagged as possible fraud are never given to it.

Guard rails that hold even with a small model:

  • A payment-instruction change stays in Important with “verify by phone”, whatever the model says.
  • A summary that quotes a dollar amount not in the email is replaced by the script summary.
  • A due date the model made up is dropped. A task due this week keeps the email in Important.
  • If the server stops answering, the run stops asking and the mail stays filed from the draft.

Mode: {{ model.mode }} ({{ settings.llm_base_url }}). auto uses a model whenever LM Studio's server is running. Set CONTROLLER_INBOX_LLM=false to never use one.

Teaching it

When a category is wrong, click the message and use Wrong category? at the bottom of the preview (or next to the category on the full email page). Write one sentence on why. The next email from that sender follows your correction, the model never overwrites the message you fixed, and the example is saved to data/training/corrections.jsonl.

Corrections saved: {{ correction_count }}. A saved correction cannot clear a payment-instruction warning on a new message.

For fraud flags, use the Fraud check panel on the email: “Not fraud”, trust the sender or their whole domain, or report it. Manage trusted domains (for example your own company's) on the Fraud check page, or list them in CONTROLLER_INBOX_TRUSTED_DOMAINS.

Running it every morning

Double-click CloseDesk.bat (Windows) or CloseDesk.command (Mac) in the project folder. It reads the drop folder, lets the model read, writes today's digest, and opens this dashboard.
